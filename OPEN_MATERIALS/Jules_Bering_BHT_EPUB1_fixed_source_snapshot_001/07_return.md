# Return

Return is not reversal.

Return restores contact with the relation that made the present movement possible.

Return may reach:

the source;
the first naming;
the evidence;
the qualification;
the earlier branch;
the human purpose;
the prior bearing;
the point where consequence entered.

A later meeting does not receive the earlier meeting itself.

It receives what has been deliberately made present:
a trace, a question, a decision, an unresolved edge, a path of recognition.

Let the later meeting ask:

What arrived from there?
What changed?
What was added?
What did not travel?
What remains uncertain?
Does this still fit?
Where must noticing begin again?

Return may confirm, revise, release, or begin elsewhere.

Its value is not that it restores the past.

It restores relationship.
